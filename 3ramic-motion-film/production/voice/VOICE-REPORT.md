## To replace a voice with a human recording

Record the line following `production/acting-direction.fa.md`, save it as 48 kHz (or 44.1 kHz) 16-bit mono WAV at `public/audio/voice/<line>.wav`, then run `npm run timeline`. The film re-times every shot, subtitle and mouth shape to the new file (its checksum no longer matches the synthetic alignment, so timing comes from the recording's own speech energy).
