# پروندهٔ استعفای سرامیک‌ها — 3ramic

ریلز اینستاگرام، عمودی ۱۰۸۰×۱۹۲۰، ۳۰ فریم در ثانیه، حدود ۳۹٫۷ ثانیه، با دیالوگ فارسی، زیرنویسِ فارسی و موسیقی و افکت‌های اختصاصی. کل فیلم با کد ساخته شده است (Remotion + React + Three.js) و روی کامپیوتر خودتان، بدون هیچ سرویس پولی، رندر می‌شود.

> **3ramic — هر سرامیکی، جای خودش.**

## داستان در یک نگاه

کاشیِ کفِ یک حمامِ ۶ متری از جایش بیرون می‌پرد و فریاد می‌زند «من دیگه اینجا کار نمی‌کنم!» و استعفانامه‌اش را به دوربین می‌کوبد. یک کارآگاهِ اردکی پرونده را باز می‌کند و سه مظنون پیدا می‌کند: **طرحِ شلوغ**، **بندکشیِ مشکی** و **روشوییِ غول‌پیکر**. تشخیص: «متراژ که عوض نمی‌شه… انتخاب‌ها باید با هم جور باشن.» — «کارِ سه‌رامیکه!». با یک دوربینِ ثابت، همان حمام با انتخاب‌های هماهنگ عوض می‌شود (مقایسهٔ قبل و بعد، «همون ۶ متر»)، کاشیِ طرح‌دار به‌عنوان یک قابِ کوچک جای درستش را پیدا می‌کند («این‌جا جای منه!»)، و کاشی استعفایش را پس می‌گیرد… «با پاداش!». در آخر، روی جملهٔ «هر سرامیکی، جای خودش» سرِ جای خودش در کف می‌نشیند.

## وضعیت — صادقانه

- ✔ **همهٔ شخصیت‌ها حرف می‌زنند**: ۱۶ خط دیالوگ با پنج صدای متفاوت (نه یک صدا با زیر و بمیِ دستکاری‌شده). همه با صدای مصنوعیِ متن‌باز و رایگان ساخته شده‌اند.
- ✔ **تلفظ برند**: همیشه «سه‌رامیک» (/serˈɑmik/)؛ هیچ‌جا «تری‌رامیک». نوشتار روی تصویر همیشه `3ramic`.
- ✔ **فهم‌پذیریِ گفتار** با نرم‌افزارِ تشخیص گفتار (Whisper) سنجیده شد: ۰٫۹۸ برای تک‌خط‌ها و ۰٫۹۶ داخلِ میکسِ نهایی، با موسیقی و افکت‌ها.
- ⚠ **کیفیتِ بازیگری شنیده نشده است.** این صداها خوانندهٔ خنثی‌اند: ریتم، مکث و تنوعِ لحن تنظیم شده، اما احساس و شوخ‌طبعیِ واقعی را فقط بازیگر می‌آورد. پیشنهاد جدی: پیش از انتشار، خط‌ها را با بازیگر ضبط کنید (راهنما پایین‌تر).
- ⚠ **هویت بصریِ برند تأیید نشده است.** سایت 3ramic.ir از این محیط باز نشد و لوگو یا کد رنگی هم همراهِ درخواست نبود. پس هیچ رنگ یا لوگویی ساخته یا «رسمی» نامیده نشد: کارت پایانی خنثی (مشکی/کاغذی) است و جای لوگو منتظر فایل رسمی است.
- ⚠ **طول ۳۹٫۷ ثانیه** است، یعنی ۱٫۷ ثانیه بیشتر از هدفِ ۳۲ تا ۳۸ ثانیه. دیالوگ عمداً تند نشد (طبق خواستهٔ بریف) و صحنهٔ اصلیِ تغییرِ حمام هم کوتاه‌تر از این خوانا نمی‌ماند.
- ℹ هیچ فایل ZIP یا ویدیوی مرجعی (`3ramic-final(4).mp4`) همراهِ این گفتگو پیوست نشده بود؛ پروژه از روی سورسِ همین فیلم که در مخزن بود بازسازی شد.

جزئیات و امتیازدهی: `docs/QA-REPORT.md`.

## نصب روی ویندوز (یک بار)

1. **Node.js** نسخهٔ LTS (۲۰٫۱۹ یا جدیدتر) را از https://nodejs.org نصب کنید.
2. **Python 3.9+** را از https://www.python.org/downloads/ نصب کنید و هنگام نصب گزینهٔ «Add python.exe to PATH» را تیک بزنید. (فقط برای ساختن دوبارهٔ صدا لازم است؛ برای رندر لازم نیست.)
3. فایل ZIP را باز کنید، مثلاً در `C:\3ramic-RELEASE-MASTER`.
4. پنجرهٔ PowerShell را در همان پوشه باز کنید (در File Explorer: نوار آدرس → `powershell` → Enter) و بزنید:

```powershell
npm ci
```

این دستور دقیقاً همان نسخه‌های قفل‌شده در `package-lock.json` را نصب می‌کند. اولین بار چند دقیقه طول می‌کشد و Remotion خودش یک مرورگرِ Chrome Headless دانلود می‌کند.

5. سلامت پروژه را بررسی کنید:

```powershell
npm run validate
```

باید پیام «no release-blocking problems» را ببینید. هشدارهای ⚠ چیزهایی هستند که تصمیمش با شماست (مثل لوگو).

## دیدن و ویرایش در Remotion Studio

```powershell
npm run studio
```

مرورگر روی http://localhost:3000 باز می‌شود. `ThreeRamicFilm` فیلم کامل است؛ در پوشهٔ **Scenes** هر صحنه جداست، در **Instagram** کاور هست و در **QA** لحظه‌های کلیدی برای کنترل کیفیت.

## رندر

| دستور | خروجی | توضیح |
|---|---|---|
| `npm run render` | `out\3ramic-reel-1080x1920.mp4` | نسخهٔ نهایی ۱۰۸۰×۱۹۲۰، H.264 + صدای AAC استریو |
| `npm run render:preview` | `out\3ramic-reel-540x960.mp4` | پیش‌نمایشِ سریع با نصفِ وضوح |
| `npm run cover` | `out\instagram\cover-1080x1920.jpg` | کاورِ ریلز |
| `npm run stills` | `out\qa\frames\` و `out\qa\contact-sheet.jpg` | فریم‌های کلیدی و برگهٔ تماس (نیاز به `pip install pillow`) |

- رندر **تکه‌تکه** انجام می‌شود (`out\chunks\`). اگر کامپیوتر خاموش شد یا رندر را قطع کردید، همان دستور را دوباره بزنید تا از جایی که مانده ادامه دهد. **بعد از هر تغییر در فیلم، پوشهٔ `out\chunks` را پاک کنید** تا تکه‌های قدیمی دوباره استفاده نشوند.
- رندرِ پیش‌فرض فقط با CPU کار می‌کند (WebGL نرم‌افزاری) و روی یک لپ‌تاپ معمولی حدود ۱ تا ۲ ساعت طول می‌کشد. روی کامپیوتری با کارت گرافیک، قبل از رندر بزنید:

```powershell
$env:REMOTION_GL = "angle"
npm run render
```

- رندرِ یک‌مرحله‌ای بدون تکه‌کردن هم هست: `npm run render:direct`.

## صدا

فیلم فقط یک فایل صدا پخش می‌کند: `public\audio\mix.wav` (دیالوگ + موسیقی + افکت + صدای فضای حمام، میکس‌شده و نرمال‌شده). موسیقی و افکت‌ها کاملاً با کد ساخته شده‌اند (هیچ نمونه‌صدای آماده‌ای استفاده نشده)؛ فایل‌های جداگانه در `public\audio\music\score.wav` و `public\audio\sfx\` هستند.

ساختن دوبارهٔ میکس (مثلاً بعد از عوض‌کردن یک صدا):

```powershell
pip install numpy
npm run audio
```

نتیجهٔ اندازه‌گیری‌ها (بلندی، پیک واقعی، سازگاری با مونو، فاصلهٔ دیالوگ از موسیقی) در `production\qa\audio-report.json` نوشته می‌شود.

### جایگزین‌کردنِ صداها با بازیگر (پیشنهادِ اصلی پیش از انتشار)

1. متن، حس، تأکید و سرعتِ هر خط در `production\acting-direction.fa.md` آمده است.
2. هر خط را جدا ضبط کنید: WAV مونو، ۱۶ بیت، ۴۸ کیلوهرتز، بدون افکت. نام فایل شناسهٔ خط است (`L01.wav` تا `L16.wav`).
3. فایل‌ها را در `public\audio\voice\` جایگزین کنید و بزنید:

```powershell
npm run timeline
npm run audio
npm run validate
```

طولِ نماها، زمان‌بندیِ زیرنویس، حرکتِ دهانِ شخصیت‌ها، افکت‌ها و موسیقی همه خودکار با ضبطِ جدید هماهنگ می‌شوند. هیچ عددی برای زمانِ دیالوگ دستی در کد نوشته نشده است.

### ساختنِ دوبارهٔ صداهای مصنوعی (اختیاری)

```powershell
pip install numpy onnxruntime onnx
npm run voices:setup      # دانلودِ یک‌بارهٔ مدل‌های صدا از Hugging Face (حدود ۴۵۰ مگابایت)
npm run voices            # ۶ برداشت از هر خط در production\takes\
npm run voices:select     # انتخابِ بهترین برداشت و نصب در public\audio\voice\
npm run timeline
npm run audio
```

برای انتخابِ خودکار بر اساسِ فهم‌پذیری، پیش از `voices:select` بررسیِ Whisper را اجرا کنید (سنگین؛ چند گیگابایت):
`pip install torch torchaudio transformers soundfile` و سپس `python scripts\audio\voice_analyze.py`.
تلفظِ دقیقِ هر خط در `production\phonemes.json` است؛ نام برند همیشه `serˈɑmik`.

## برند

- **لوگو:** فایل رسمی (SVG یا PNG شفاف) را در `public\` بگذارید و در `src\config\brand.ts` مقدار `logo.file` را برابر نام فایل کنید. لوگو بدون تغییر رنگ یا کشیدگی نشان داده می‌شود.
- **رنگ‌ها:** کدهای رسمی را در `colors` همان فایل بنویسید و `verification.status` را `"verified"` کنید. تا وقتی تأیید نشده، فیلم عمداً رنگ برند ندارد و `npm run validate` جلوی رنگِ ساختگی را می‌گیرد.
- جزئیات: `docs\BRAND-VERIFICATION.md`.
