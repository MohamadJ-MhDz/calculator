# کپشن ریلز

متنِ زیر را بدون تغییر کپی کنید (از خطِ اول تا آخر):

```
سرامیک‌های این حمام استعفا دادن! 🧾

یه کارآگاهِ اردکی پرونده رو باز کرد و سه مظنون پیدا کرد:
۱. طرحِ شلوغ
۲. بندکشیِ مشکی
۳. روشوییِ غول‌پیکر

متراژ همون ۶ متره؛ فقط انتخاب‌ها با هم جور شدن.

مدل‌های هماهنگ رو توی 3ramic ببین: 3ramic.ir
هر سرامیکی، جای خودش.

شما بودید اول کدوم مظنون رو بازداشت می‌کردید؟ عددش رو بنویسید 👇
```

## نسخهٔ کوتاه (برای آزمایش با Trial Reels)

```
این حمام ۶ متری کاشی‌هاش رو از دست داد 😅
مقصر کی بود؟ ۱، ۲ یا ۳؟
مدل‌های هماهنگ: 3ramic.ir — هر سرامیکی، جای خودش.
```

## نکته‌ها

- لینک در کپشنِ اینستاگرام کلیک‌خور نیست؛ اگر لینکِ سایت در بیوی صفحه هست، می‌توانید «لینک در بیو» را هم اضافه کنید.
- در کپشن هیچ ادعای قیمت، تخفیف، گارانتی یا «بزرگ‌تر نشان دادنِ هر فضایی» نیامده است؛ لطفاً اضافه نکنید مگر اینکه درست و تأییدشده باشد.
- نام برند در نوشتار `3ramic` است و در گفتار «سه‌رامیک».
